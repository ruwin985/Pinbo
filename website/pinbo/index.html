Core Features

围绕“录完就能发”的核心流程设计

录制时保持轻量，编辑时保留调整空间，导出时统一合成成适配短视频平台的竖版作品。

01

前后双摄同框

后摄拍场景，前摄拍人物，适合探店、开箱、教程、vlog 等需要真人出镜的内容。

02

屏幕 + 摄像头录制

Mac 端支持录制桌面、窗口或应用，并把摄像头作为画中画加入，适合软件演示和课程录制。

03

实时字幕

录制过程中将语音转成字幕，保留时间戳，后续可在编辑页继续修改文字和样式。

04

可拖拽画中画

前摄小窗的位置、大小、圆角不在录制时写死，录后依旧可以调整构图。

05

非破坏式编辑

保留原始视频和时间轴元数据，字幕、画中画、音乐都能独立调整，减少重录成本。

06

一键导出

统一合成竖版视频，面向抖音、微信视频号、小红书等发布场景。

Workflow

从录制到发布，只保留关键步骤

1

选择录制源

在 iPhone 使用前后摄，在 Mac 选择屏幕、窗口或应用作为主画面。

2

边录边生成字幕

录制过程实时生成字幕，并保存为可编辑的字幕分段。

3

调整画中画与字幕

录后重新摆放人物小窗，修正字幕文字，按作品风格微调。

4

导出发布

将主视频、前摄、字幕和音乐一次性合成，生成最终作品。

Platforms

一个工程，覆盖移动拍摄与桌面录屏

当前工程采用共享 Core + 平台独立采集层：iOS 使用 UIKit 与 AVFoundation，macOS 使用 AppKit、ScreenCaptureKit 与 AVFoundation。

iOS

适用于前后双摄同框录制、屏幕录制、移动端草稿管理。

建议 iPhone 12 及以上设备

macOS

适用于屏幕录制、窗口录制、摄像头画中画与桌面教程制作。

支持 macOS 12.3 及以上系统
